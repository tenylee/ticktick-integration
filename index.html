📋 TickTick × OpenClaw 集成方案

一、TickTick API 现状

类型说明限制
官方 Open APIOAuth2 认证，需申请开发者账号功能有限，主要面向三方应用集成
内部 APIWeb/App 客户端使用的接口功能完整，但非官方公开

📌 BA API 文档在 developer.ticktick.com，需要注册开发者应用获取 Client ID/Secret

二、集成到 OpenClaw 的三种路径

A
自建 Skill
写 TickTick Skill 封装 API 调用，通过 OpenClaw skill 机制加载
✅ 推荐
B
MCP Server
使用社区 MCP Server (如 mcp-ticktick)，OpenClaw 连接作为工具源
备选
C
curl / CLI 脚本
直接调 TickTick API，类似 lark-cli 方式，最快上手
备选
